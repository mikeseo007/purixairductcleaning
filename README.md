# Purix Air Duct & Dryer Vent Cleaning — Website

SEO-focused marketing site for [Purix Air Duct & Dryer Vent Cleaning](https://purixairductcleaning.com/), based in Miami, FL, with service across Miami-Dade and Broward and in Boca Raton, Naples and Cape Coral.

## Stack

- [Astro](https://astro.build) — static HTML output, fast loads, strong SEO
- Tailwind CSS v4
- `astro:assets` for responsive WebP images
- `@astrojs/sitemap` for `sitemap-index.xml`
- Netlify hosting + Netlify Forms for service requests

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Netlify builds with `npm run build` and publishes `dist/` (see `netlify.toml`).

Service pages (`src/data/services.ts`) and city pages (`locations` in `src/data/site.ts` plus `src/data/location-content.ts`) are both generated by `src/pages/[slug].astro`. To add a city, add it to `locations` (with `region`, `lat`, `lng`) and write its copy in `location-content.ts`; it then appears automatically in the header, footer, quote form and every locations section, with its distance from the office calculated from the coordinates. Retired URLs are 301-redirected in `netlify.toml` (for example `/hvac-system-cleaning/` → `/hvac-cleaning/`, plus old WordPress URLs).

## Editing content

- `src/data/site.ts` — business name, address, phone, email, hours, service areas, social links, the Google Maps embed and Google reviews. When new Google reviews come in, paste them into `reviews` word for word and update `google.rating` / `google.reviewCount`.
- `src/data/services.ts` — service groups and every service page's copy, FAQs, images and related services
- `src/data/location-content.ts` — homepage (Miami) and city page copy and FAQs
- `src/content/blog/*.md` — blog posts (frontmatter: `title`, `description`, `date`, `cover`, `coverAlt`, `service`)
- `src/assets/images/` — photos. Drop new photos here in any common format and name. `scripts/optimize-images.mjs` runs before every `npm run dev` and `npm run build` (including on Netlify), or on demand with `npm run images`. It converts photos to WebP (max 2400px, quality 82, EXIF rotation applied, metadata stripped), renames them to kebab-case and updates their references in `src/`. Transparent PNG logos stay PNG, and oversized JPGs in `public/` are recompressed in place. HEIC isn't supported, so export iPhone photos as JPG first. Astro then builds responsive WebP sizes from these files. Keep `public/og-image.jpg` a 1200×630 JPG, because some apps don't show WebP link previews.
- `src/data/photos.ts` — the photo library: every photo with its alt text and a "family" for look-alike shots. Pages use it to avoid showing the same photo twice; the services section and related-service cards automatically swap to an unused photo. When you add a photo, add it here too.

Location pages show only the phone number in page content; the full address, hours and email appear in the header, footer and contact page.

## Design system and motion

- **Type:** Bricolage Grotesque (headings, `font-display`) and Plus Jakarta Sans (body), both self-hosted variable fonts.
- **Tokens and components** live in `src/styles/global.css`: navy, sky and lime palettes, `card`, `card-hover`, `icon-chip`, `spotlight` (a glow that follows the pointer), `text-gradient` and the `btn-*` buttons. The wind-stream graphic (`AirStream.astro`) is used only in the inner-page banner (`PageHeader.astro`), so it appears once per page.
- **Reveal on scroll:** add `data-reveal` to any element. Variants are `left`, `right`, `zoom` and `blur`, for example `data-reveal="left"`. Add `data-stagger` to a list or grid to reveal its children one after another. Both are driven by `src/scripts/motion.ts`.
- **Scroll-linked effects** (pure CSS scroll timelines, in browsers that support them): `hero-parallax`, `parallax` (image drift inside its frame), `unmask` (image clip reveal), `fill-line` / `fill-line-y` (process timeline), `scale-in` (CTA card) and the top `scroll-progress` bar. Unsupported browsers show the final state.
- **Services section** (`ServicesSection.astro`) is a tabbed explorer: one tab per service group, with the group's photo and linked service pages. Without JavaScript all groups are shown stacked, so every link stays crawlable.
- **Other motion:** count-up numbers (`data-count`), header that compacts on scroll and the marquee ribbon in `CtaBand.astro`.
- Content stays visible without JavaScript. All motion is turned off for visitors who set "reduce motion" in their OS.

## SEO features

- Unique title, meta description, H1 and canonical URL on every page
- JSON-LD: one `HVACBusiness` (Miami address, phone, email, Sun–Fri 24-hour opening hours, service areas), `WebSite`, `Service`, `FAQPage`, `BreadcrumbList`, `BlogPosting`
- Grouped services section on the homepage, every service page, the services page, the service-areas page and each location page
- Open Graph / Twitter cards, XML sitemap, `robots.txt`

## Service request form

The form posts to Netlify Forms (`service-request`) with a honeypot field and redirects to `/thank-you/`. After the first deploy, enable email notifications in Netlify under **Site configuration → Forms → Form notifications** and send them to Info@purixairsolution.com.
